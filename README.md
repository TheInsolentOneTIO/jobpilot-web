# JobPilot Web

Учебный MVP: React/Vite frontend и FastAPI backend. Вакансии запрашиваются из открытого API «Работа России»; история, профиль и избранное хранятся в браузере (`localStorage`).

## Быстрый запуск для Windows

1. Установите Python 3.11+ и Node.js LTS (вместе с npm), затем откройте новую `cmd.exe` или PowerShell.
2. Откройте папку проекта и выполните:

```powershell
cd C:\path\to\jobpilot-web
.\start.bat
```

Скрипт создаёт `backend\.venv`, устанавливает зависимости из `backend\requirements.txt` и `frontend\package.json`, запускает FastAPI и Vite в двух отдельных окнах, ждёт их готовности и открывает `http://127.0.0.1:5173/`.

Для проверки доступности инструментов без запуска используйте:

```powershell
.\start.bat --check
```

Остановите серверы, закрыв открытые окна `JobPilot API` и `JobPilot Frontend`.

## Проверка

- Backend: `http://127.0.0.1:8000/api/health`
- Frontend: `http://localhost:5173/`

## Ограничения MVP

- Единственный активный источник — открытый API «Работа России»; сеть или ограничения источника могут привести к пустой выдаче или ошибке источника.
- Для сети через прокси задайте `HTTP_PROXY` в `backend\.env`; файл `.env` не включается в Git.
- Расширенные фильтры профиля сохраняются локально, но пока не передаются в API.
- Уведомления и отклики не реализованы; отправка откликов не выполняется.

## Публикация на Render

1. Поместите `jobpilot-web` в Git-репозиторий и в Render выберите **New → Blueprint**, указав файл `render.yaml`. Публикация выполняется только после нажатия **Deploy Blueprint**.
2. Для сервиса `jobpilot-web-api` (Python Web Service, Free) команда запуска уже задана: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`.
3. После создания API скопируйте его HTTPS-адрес и укажите его как `VITE_API_URL` у `jobpilot-web-frontend` (Static Site), без завершающего `/`.
4. После создания адреса Static Site укажите его как `CORS_ORIGINS` у API. Допустимо несколько адресов через запятую; локальные адреса уже разрешены.
5. Сохраните переменные с пересборкой: Vite подставляет `VITE_API_URL` при сборке. Не добавляйте ключи или `.env` в репозиторий.
